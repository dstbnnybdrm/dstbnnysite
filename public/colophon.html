colophon

an inscription at the end of a book or manuscript, usually with facts about its production.

this site was created initially as a simple link-in-bio site for my projects and commission information, like a fancier carrd or Linktree, but over time it’s shifted to being a very personal creative outlet for me. now it’s as much of a creative project in and of itself. i always loved the concept of the internet being used as a means to express yourself and connect with others. these days that usually means social media, but i was never great with social media for whatever reason and still find it very, very exhausting. making this site led to the discovery of the independent web and all the other adjacent movements (the Indie Web, Web Revival, Small Web, etc.) which has felt a lot less suffocating and brings (back) a lot more personality to the Web, i think.

this site is coded by my real human/rabbit hands with Neovim and built using Eleventy, you can find the source code at its GitHub repo. this site is proudly hosted on Neocities and deployed using Bret Comnes’ Deploy to Neocities Github Action. to dither images i use makeworld’s didder command-line tool. there is zero generative “AI” use on this site and it makes me a little bit sad to have to disclose that these days lol :'). GenAI sucks.

the design of this site is kind of an exercise in doing lot with a little? as such i sort of roughly follow the principles of brutalist web design (as outlined by David Copeland). i use text and ASCII art a lot as visual embellishments, i just like the aesthetic. i always thought, like, the simplicity of CLI applications looked really cool. i also take lots of inspiration from personal sites from the 90s up to the early 2000s and use some of the common tropes found among them for fun and nostalgia but also as a nod to a less serious and more playful era of the internet. the main hub page (viewed on desktop) is modelled after GeoCities sites that used <framesets> for their page layouts, though instead it uses an <iframe> for the main content à la some personal sites i’ve seen from the 2000s (and now!).

the colours used in this site are colour-picked and slightly tweaked from various frames in 1992’s Sailor Moon—but the version tinted pink from film degradation, not the original! though it wasn’t the original artistic intent, i always thought the pink hue was really endearing and warm feeling. for the light theme i picked mainly colours from scenes in Usagi’s bedroom (because, well y’know) and for the dark theme i used colours from night shots, typically from outside.

i try to keep the site WCAG-AA compliant, i can’t verify whether it’s fully compliant or not, so i won’t claim it to be, but i do strive to keep accessibility in mind at all times. i periodically test this site using a screen reader, NVDA for Windows. this site should be navigable using just a keyboard, and also should remain largely functional without JavaScript. if you have any issues with regards to accessibility please feel free to send me a message about it!

this site features a blank page according to the recommendations of the TPILB-Project. it’s just kind of silly, but i also like the sentiment behind it: a blank page for relaxing the restless mind.

this site features a for page, conceptualized by Bino Varghese.
