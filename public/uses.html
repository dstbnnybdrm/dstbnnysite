uses

collections of software, hardware, and gear that i use to work and create!

uses pages are a concept i believe started by Wes Bos. it’s originally geared more towards tech people and developers but i’ve adapted it for my own use (ha).

general

Shimeji-ee
desktop pets that hang out on your screen. they’re fun and keep me company! you can find a bunch of shimeji on their official deviantArt group, and i’ve also found a few on this older tumblr blog lol
Obsidian.md
markdown-based note-taking app!
Thunderbird
free and open-source email client! also has a built-in RSS feed reader!
PowerToys
bunch of utilities to make Windows more bearable to use!
Flow Launcher
file searcher and app launcher for Windows; faster than the one in Power Toys
Dvorak
the keyboard layout i use, opposed to QWERTY! (here’s some reasons why!)
AutoHotKey
software and scripting language to create macros, shortcuts, hotkeys, etc., i use it to emulate parts of an HHKB keyboard lol
f.lux
adjusts the temperature of your display to adapt to the time of day! helps me reduce eye strain since i look at screens all day
Musicbee
wonderful player, i love it especially for its scanning, organizing, and tagging features
WACUP
(i.e. the WinAmp Community Update Project )
a simple and very customizable player based off of a classic! you can find a bunch of fun skins here!

music

software

Ableton
my main DAW for production these days
REAPER
the DAW i use primarily for mixing
FL Studio
DAW i used to use primarily for ~5 years, though i still occasionally open it up as a VST
Renoise
my main tracker DAW, i like its workflow more than a traditional DAW for some genres/styles
SynthV
free vocal synthesizer (in the vein of VOCALOID and such), just started messing around with it and it’s been very fun!
MiniMeters
super simple but very helpful and sleek looking audio metering app! i use it all the time

hardware

Focusrite Scarlett 4i4 (3rd Gen)
audio interface
Yamaha HS5s
studio monitors
Arturia MiniLab MkII
MIDI keyboard
Grado SR80x
my main set of headphones for casual use
Beyerdynamic DT 990 Pro
studio headphones i use for more serious work lol
Shure SM57
super reliable dynamic microphone! the only studio quality mic i have right now so i use it for everything
Blue Yeti
USB condenser microphone; i used it when i didn’t have any other options and it worked fine! i still occasionally use it when i intentionally want the specific quality that it has
KS-3000 dynamic microphone
random karaoke mic i found in our basement. i use it sometimes if i want to be lo-fi
Optimus CTR-117
surprisingly decent sounding cassette recorder i managed to thrift! i use it both to record from the DAW to cassette and back and also for its preamp by bypassing the record function. lately my main guitar drive has been that preamp
QFX Retro-39 Shoebox Recorder
relatively cheap cassette recorder i got online, it’s nothing too amazing but it definitely does its job well enough! i mostly use it to record with its onboard mic
modded Byron Static player
probably the cheapest cassette player/recorder i could find online at the time. i did a pretty easy and common motor speed control mod to it.

code

Neovim
my IDE/code editor (check here for my config :3c)
Windows Terminal
terminal emulator for Windows
WSL(2)
lets me run a Linux environment in Windows. i use the Debian distribution

web

deploy-to-neocities
Github action to deploy this site’s files to Neocities
Eleventy
simple static site generator
Nunjucks
HTML templating engine; removes a lot of the code reuse i would have to do before
PostCSS
tool for transforming CSS code using JavaScript
Prettier
code formatter for HTML, CSS, JavaScript, and Markdown. for Nunjucks i use this jinja template plugin
File Garden
simple, no frills file hosting site; used to host audio files and images!
